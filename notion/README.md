# Notion publishing package

`Balford-Engineering-Hub.md` is an import-ready Notion page that connects:

- the Ask engineering console
- the public site search
- six calculators
- the eighteen-document technical PDF series
- the RFQ / drawing-upload route

## Import

1. In Notion, open the destination workspace or parent page.
2. Choose **Settings → Import → Markdown**.
3. Import `Balford-Engineering-Hub.md`.
4. Review links, headings and tables in Notion.
5. Publish the page and enable search-engine indexing.

Do not copy metrics such as the PDF count unless the linked source still contains them.
