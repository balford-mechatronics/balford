# Chrome Web Store listing

## Name

Balford Stamping Calculators

## Summary

Offline deep drawing, blanking force and bend allowance calculators for sheet-metal engineers.

## Detailed description

Three practical shop-floor calculators in one lightweight extension:

- Deep drawing: drawing ratio, C1 coefficient, punch force, blank-holder force and die-radius guidance.
- Blanking: circular cutting force, stripping force and punch compressive stress.
- Bending: bend allowance, bend deduction, outside setback and flat length from a K-factor.

Each result updates instantly and all calculations run locally. The extension
requests no browser permissions, includes no analytics and sends no entered
dimensions to a server.

The calculators are first-pass engineering estimates. Confirm critical tooling
and production decisions against the drawing, material lot, equipment and first
article.

Links open Balford's full calculator hub, engineering answer console and free
technical PDF library when selected.
