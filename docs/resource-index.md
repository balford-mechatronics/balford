# Balford public engineering resource index

This index connects the GitHub calculators and reference data to the public
resources maintained on balford.net.

## Ask

- [Engineering answer console](https://balford.net/ask/)
- [Topic coverage board](https://balford.net/ask/topics/)
- [What is fine blanking?](https://balford.net/ask/q/what-is-fine-blanking/)
- [What is thinning deep drawing?](https://balford.net/ask/q/what-is-thinning-deep-drawing/)
- [What does a DFM review cover?](https://balford.net/ask/q/what-is-dfm-and-what-does-a-review-cover/)

The console cites the published Balford page behind each answer and states when
the public material does not cover the question.

blanking and bend checks from this repository. The extension can be loaded
unpacked; no Chrome Web Store distribution is planned.
